# 📌 Taskily

Taskily is a modern task management application built with **Flutter**, designed to help users organize and prioritize their daily activities using the **Eisenhower Task Management Method**. The app focuses on productivity while delivering a beautiful and smooth user experience through glassmorphism design and fluid animations.

---

## ✨ Features

- 🧠 **Eisenhower Task Prioritization**
  - Categorize tasks by urgency and importance
  - Helps users focus on high-value activities

- 🎨 **Glassmorphism UI**
  - Modern and visually appealing interface
  - Smooth animations and interactive elements

- 🏗 **Stacked Architecture**
  - Clean and scalable project structure
  - Clear separation between UI, business logic, and services

- ☁ **Firebase Backend**
  - Offline Support and data synchronization
  - Secure cloud storage

- ⚡ **Optimized User Experience**
  - Intuitive navigation
  - Fast and responsive performance

---

## 🛠 Tech Stack

- Flutter
- Stacked Architecture
- Firebase
- Custom Animations & UI Design

---

## 🎯 Project Goal

Taskily demonstrates advanced Flutter development practices, clean architecture implementation, and modern UI/UX design while providing a practical productivity tool.
